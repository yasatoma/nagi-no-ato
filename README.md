# 凪のあとに、声が残る

嵐の観測所。六人の夜。残された音を、最後まで聴いて。

ブラウザで遊ぶ、日本語のオリジナル・ミステリービジュアルノベルです。人物の死・事故・喪失を扱います。流血画像や突然の大音量はありません。音の手掛かりはすべて文章でも読めます。

## 遊び方

**[ブラウザで遊ぶ（GitHub Pages）](https://yasatoma.github.io/nagi-no-ato/)** — インストール不要です。

Node.js 22以降が入った環境で、このフォルダーから実行します。**プレイに npm install は不要**です。

```powershell
npm start
```

[ゲームを開く](http://localhost:4173)。止めるときはサーバーのターミナルで Ctrl+C。Windowsでは `Start-Game.cmd` からも起動できます。HTMLのダブルクリックではなく、ローカルHTTPサーバー経由で開いてください。

PCは横長、スマートフォンは縦持ちを推奨。スマートフォンでは同じWi-Fiにつなぎ、PCのLANアドレスに `:4173` を付けて開きます（例：`http://192.168.1.10:4173`）。PCのアドレスは `ipconfig` のIPv4欄で確認できます。接続には端末間通信が許可されたネットワークが必要です。ファイアウォール設定は自動変更しません。インターネットへの公開は不要です。

## 機能

- 本編、行動・調査による分岐、複数の結末。恋愛ポイントはありません。
- バックログ、手掛かりの記録帳、6枠の手動セーブ、自動セーブ、読み込み前の記録。
- オート、未読で止まる既読スキップ、文字速度・大きさ・音量・演出低減の設定。
- 読了した結末の栞、任意に開くヒント、読了後の章の読み返し。
- 引き継ぎコード、テキストファイル書出／読込、QR表示、QR画像の読取。
- 6枚の背景、5人の透過立ち絵、場面別のオリジナル合成音楽・雨・効果音。

本文は約4.9万字（全分岐合計）。終盤まで読む一周は約3.5万〜4.1万字です。**初回の目安は約1.5〜2.5時間**、複数の道を読み返すと約3時間前後から。早い段階の結末もあります。読み方・調査の選び方・既読スキップの使用で大きく変わります。これは文章量に基づく目安で、人による所要時間の実測ではありません。

## 操作

| 操作 | 内容 |
|---|---|
| 本文クリック／タップ、Enter、Space | 全文表示 → 次へ |
| Esc | メニュー／パネルを閉じる |
| L | 履歴 |
| S | セーブ |
| A | オート切替 |
| 画面下のボタン | 履歴・保存・読込・自動送り・設定 |

選択肢では自動送りを止めます。証拠不足の選択肢には理由を表示し、追調査に戻れます。ブラウザが非表示になると音と自動送りを止めます。音はプレイ開始などの操作後に鳴ります。台詞の音声読み上げはありません。

## 保存・端末間引き継ぎ

保存先はブラウザの `localStorage`、キーは `nagi.archive.v1` です。ブラウザ・URLのホスト名・ポートごとに別の保存場所になります。ブラウザのデータ削除やプライベートモードでは記録を失う場合があるので、長く遊んだらコードかファイルも残してください。

1. 元端末で「引き継ぎ」→「コードを発行」。
2. コードを全文コピー、または `nagi-transfer.txt` を保存。
3. 新端末で同じゲームを開き、「引き継ぎ」に貼り付けるかファイルを選択。
4. 「コードを確かめる」→表示された章を確認して復元。

QRはコードそのものを格納しています。端末のQR読取でテキストを取り出すか、ゲーム内「QRの画像・写真から読み取る」で画像を選択できます。画像は端末内だけで処理します。大きな履歴でQR容量を超えた場合にも、コードとファイルは使えます。

引き継ぐのは現在位置・選択内容・調査結果・履歴・既読・読了記録。手動保存枠・設定・章開始の栞は元端末のままで、新端末へは移しません。新端末の既読・読了記録には統合し、手動保存は上書きしません。コードは暗号化された秘密情報ではなく、進行状況を表すデータです。

## 構成

```text
index.html            エントリーポイント
assets/               本作用の生成背景・透過人物・アイコン
src/app.js            表示・操作・保存・引き継ぎUI
src/engine.js         分岐・検証・引き継ぎ形式
src/story*.js         本編（内容が分かるため初見では開かないでください）
src/audio.js          オリジナルWeb Audio音響
src/style.css         PC・縦画面のUI
src/vendor/           同梱QRライブラリ
tools/serve.mjs       ローカル静的サーバー
tests/                エンジンと実ブラウザの検証
docs/SPEC.md          ネタバレなしの仕様
docs/WBS.md           制作進捗
docs/ART-PROMPTS.json  使用した画像生成プロンプト
docs/spoilers/        真相設計・監査・分岐別の計測（ネタバレあり）
```

ローカルサーバーは本編・素材だけを配信し、制作資料・テスト・Git情報は配信しません。GitHub Pagesでも `index.html`、`src/`、`assets/` のみを配信します。`main` へのpush時に自動テストを実行して公開します。公開リポジトリ内の制作資料にはネタバレが含まれます。

## 検証

```powershell
npm ci --cache .npm-cache
npm test
# 別のターミナルで npm start してから
npm run test:browser
node tests/interaction.mjs
```

実ブラウザ検証はインストール済みMicrosoft EdgeをPlaywrightから使用します。結果は `test-results/` に保存。テストは隔離されたブラウザで実行し、プレイヤーの保存データには触れません。詳細は `docs/TEST-REPORT.md`。`test-results/` には終盤の画像も含まれるため、初見の方は開かないでください。
