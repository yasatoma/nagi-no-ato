## 時間と因果

- 録音20:41、秒打ち停止20:44は共通ルートで事件前に描写。21:14の声と同じ背景音を本文に明記し、音をオフにしても推理可能。
- 時計は針と秒打ちの機構を分離。針まで止まったという記述はない。21:08の照明停電と混同しない。
- 環が時計の停止を知らないのは厨房へ戻ったため。録音の存在と予約再生の方法は案内で聞いている。
- 最終直接目撃20:48。環の入室20:50、転倒20:52頃、退室21:03頃、返却記入21:05、集合21:10、放送21:14、発見21:26。入退室の細部は自認による説明として扱う。
- 医学的死亡時刻は断定しない。発見後は救助要請と指示に従う応急手当を描写。救助不能を通信不能とは混同しない。
- 録音室は自動施錠で、内からは鍵を使わず退室可能。外部の抜け道・秘密通路・未知の七人目を使わない。

## 事前提示と回収

| 提示 | 回収 |
|---|---|
| 廊下の独立電池式再生機・予約機能 | 停電時も予約放送が作動 |
| マイク位置への「そのままで」 | 現在の待機指示だと誤って受け取る |
| 時計三音と匙の二音 | 時間・場所の照合、再生履歴と独立して裏付け |
| 青リーダーの説明 | 現場の切れ端・袖・原本所在の矛盾 |

| 浸水警報・資料の移動 | 原本を守る行動の優先順位が分岐に結びつく |

## ミスリードの扱い

- 黒田の機材売却は別の不正。犯行を示す証拠として扱わず、隠したい理由と証言の拒絶に結びつく。
- 灯の取材録音も、それだけで絶対的アリバイにしない。
- 二階の金属音は時刻・場所とも不確かで、主人公が想像で転倒音に変えない。風の音を犯行機構へ流用しない。
- 環の袖のテープだけでは罪を断定しない。貸出票・所在の説明の変化・資料の異同と積み重ね、自認は現場資料との照合を要するものとして引き渡す。

## 分岐整合

全場面と全結末の到達性は自動探索で確認。調査は二か所のあと再調査可能。証言を強く要求して聞けなかった場合も、聞き直しで回復できる。

- 黒田の目撃を得た場合は、対決前に目撃を照合する専用場面へ進む。
- 目撃なしでも文書と所在の矛盾から質問を作れる。未知の目撃証言を主人公が引用しない。
- 調査で黒田と話していないルートにも、告白後に機材の移送票の自発的提出を描写。引き渡し場面だけが知識を先取りしないよう補正。
- 原本を保護しない場合に未編集音源を聴くノードへ進まない。
- 原本を保護しても、紬に同行しない場合・最後まで聴かない場合は関係の結びが異なる。好感度値なし。
- 各結末の後日談は、そのルートの残った資料の状態を保つ。水損資料の完全復元を都合よく約束しない。
